# 60–120 秒作业录屏脚本

> 录屏建议：1600×1000 或以上。若没有配置 `OPENAI_API_KEY`，请保留“本地演示成片”标识，并口播 / 字幕说明“本地演示，非真实 AI 生成成功”。

## 时间轴

| 时间 | 画面与操作 | 必须可见 |
| --- | --- | --- |
| 00:00–00:08 | 打开 `http://127.0.0.1:4174/?v=18`；点击“连接设备”，选择 EasyInput 串口 | 顶部“硬件已连接”和串口实体事件 |
| 00:08–00:16 | 点击“导入照片”，选择自己的肖像素材 | 上传文件名 / 原图出现在工作台 |
| 00:16–00:26 | 默认状态下转动实体旋钮，浏览至少 3 种风格 | `风格切换` 和风格名称变化 |
| 00:26–00:38 | 按 `1 / S1` 选择强度；旋钮调整；旋钮按下确认生成 | `强度大小`、强度百分比、生成状态提示 |
| 00:38–00:50 | 等待生成完成，画面自动放大 | 原图与“本地演示成片”并排显示 |
| 00:50–01:00 | 按 `2 / S2`、`5 / S5` 切换视图，并转动旋钮轮换各原始图 | 视图保持正确，素材编号连续变化 |
| 01:00–01:10 | 按 `3 / S3` 保存；再按一次证明已置灰；按 `4 / S4` 返回工作台 | 下方只新增一张，重复保存无效 |
| 01:10–01:26 | 按 `8 / S8` 进入创意显示；旋钮调窗口；按住圆心拖动 | `圆圈大小`、圆形边界和位置变化 |
| 01:26–01:32 | 按 `4 / S4` 返回；展示作品区或再次查看作品 | 回到工作台 / 作品对比 |

## 口播参考

> 我用 EasyInput 的串口输入桥连接网页。数字 1 到 8 分别对应 S1 到 S8。上传自己的照片后，默认旋钮选择风格；1 进入强度调整，旋钮微调后按下确认。当前没有配置 API Key，所以生成的是本地演示成片，只验证交互链路，不代表真实 AI 生成成功。生成后自动放大，2 切换对比并轮换素材，5 切换原图并轮换素材，3 保存且同一效果只保存一次，保存后旋钮可查看同设置效果图，4 返回。最后按 8 进入创意显示，用旋钮和鼠标调整圆形窗口。

## 证据检查

1. 至少出现一次串口实体输入事件；
2. 上传的是本人素材，不是页面示例图；
3. `1～8` 与 `S1～S8` 的行为与映射表一致；
4. `3 / S3` 重复按下不会重复保存；
5. 无 API Key 时“本地演示 / 非真实 AI 生成”文案清晰可见；
6. 总时长在 60–120 秒。
