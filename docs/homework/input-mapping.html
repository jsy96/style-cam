数字 1～8 = 实体 S1～S8 · Web Serial 115200 baud · 页面 v17

核心功能

数字 / 实体键功能说明
1 / S1强度大小旋钮 / 滚轮调整强度
2 / S2对比 / 效果切换后旋钮保持当前视图，轮换各原始图
3 / S3保存效果图只保存一次；旋钮按同风格 / 同强度轮换效果图
4 / S4工作台 / 作品弹窗打开则返回，否则查看作品
5 / S5效果 / 原图切换后旋钮保持当前视图，轮换原始图 / 效果图
6 / S6风格切换旋钮 / 滚轮切换 10 种风格
7 / S7重置为原图强度归零；旋钮轮换各原始图
8 / S8圆圈大小进入创意显示并调整窗口
