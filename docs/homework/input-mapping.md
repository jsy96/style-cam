# StyleCam 输入映射表

适用页面：`http://127.0.0.1:4174/?v=19`

当前网页数字键 `1～8` 与实体键 `S1～S8` 使用同一套映射。

## 一、1～8 / S1～S8 功能表

| 数字键 | 实体键 | 功能 | 说明 |
| --- | --- | --- | --- |
| `1` | `S1` | 强度大小 | 选中后旋钮 / 滚轮调整强度 |
| `2` | `S2` | 切换 对比图 / 效果图 | 切换后旋钮保持当前视图，轮换各原始图 |
| `3` | `S3` | 保存效果图 | 只保存一次；随后旋钮按同风格 / 同强度轮换各原始图效果图 |
| `4` | `S4` | 回到工作台 / 查看作品 | 弹窗打开时返回；未打开时查看已保存作品 |
| `5` | `S5` | 切换 效果图 / 原图 | 当前素材原图 / 效果成对切换；对比图状态下先进入效果图 |
| `6` | `S6` | 风格切换 | 选中后旋钮 / 滚轮切换 10 种风格 |
| `7` | `S7` | 效果图重置为原图 | 强度归零并显示原图；随后旋钮轮换各原始图 |
| `8` | `S8` | 圆圈大小 | 进入创意显示；旋钮 / 滚轮调整圆形窗口 |

## 二、旋钮行为

| 当前选中 | 旋钮左 / 右 |
| --- | --- |
| 默认 / `6 风格切换` | 上一个 / 下一个风格 |
| `1 强度大小` | 强度 -5% / +5% |
| `8 圆圈大小` | 圆圈缩小 / 放大 |
| `2 对比 / 效果` | 保持当前视图，轮换各原始图的对比图或效果图 |
| `3 保存效果图` | 按同一风格、强度与圆形参数轮换各原始图效果图 |
| `5 原图 / 效果` | 保持当前视图，轮换各原始图或对应效果图 |
| `7 重置为原图` | 轮换各原始图 |
| `4 查看作品` | 上一个 / 下一个作品（S4 功能保持不变） |

旋钮按下：

- 在 `1 强度大小` 时确认强度并生成；
- 在 `8 圆圈大小` 时确认当前窗口；
- 其他状态进入强度调整。

## 三、其他鼠标输入

| 输入 | 行为 |
| --- | --- |
| 鼠标滚轮 | 等价于旋钮左 / 右 |
| 点击上方照片 | 选择当前处理素材 |
| 按住画面圆圈 | 圆心精确跟随鼠标；松开左键固定 |
| 点击 `[导入照片]` | 上传自己的 JPEG / PNG / WebP |
| `1` 后按下旋钮 | 确认强度并生成本地演示成片或 AI 成片 |

## 四、串口事件协议

浏览器通过 Web Serial 连接后按行读取，支持 JSON Lines 或简洁文本。波特率 `115200`。

```text
{"type":"encoder","delta":1}
{"type":"encoder","delta":-1}
{"type":"encoder-press"}
{"type":"button","key":"S1","action":"down"}
{"type":"button","key":"1","action":"down"}
```

兼容文本：

```text
ENC+
ENC-
ENC_PRESS
S1_DOWN
1_DOWN
S8_DOWN
8_DOWN
```

## 五、保存去重规则

一张效果图会生成唯一特征值。保存后：

- `3 / S3` 置灰；
- 再次按 `3 / S3` 不会重复保存；
- 素材、风格、强度、圆圈大小 / 位置、显示区域或 AI 成片变化后，视为新效果图，`3 / S3` 恢复可用。

## 六、证据边界

- 顶部显示 `硬件已连接` 且事件区出现串口实体事件，才可作为真实硬件操作证据。
- 鼠标滚轮只是无设备时的本地操作回退，不能写成蓝牙 / 实体键盘操作。
- 未配置 API Key 时，页面只能生成“本地演示成片”，不能写成真实 AI 生成成功。
